# 世说新语 · 编书人

一个以《世说新语》为底本的纯静态网页游戏。你扮演南朝宋临川王刘义庆的门客，受命编撰一部魏晋轶事集：游历建康—洛阳—山阳—会稽，亲闻九件《世说》轶事，做出**无对错、有立场**的应对，然后落笔——记或不记、记入哪一门。你的书稿由你的取舍而成，而"风声"（政治压力）贯穿全程：有些事，记下是要招祸的。

代码仓库：[github.com/Moogg000/ShiShuo-Game](https://github.com/Moogg000/ShiShuo-Game/)

## 玩法循环

每一件事经历四个阶段：**遇事**（情境叙述）→ **应对**（三选一，三种真实存在的解读立场，无对错）→ **后话**（知音或诤友名士引原典回应你的立场）→ **落笔**（记入《德行》《言语》《方正》《雅量》《任诞》《栖逸》其中一门，或不记）。

- **精神坐标**：开场"三试"把玩家放在三条魏晋轴线上（名教↔自然、情↔理、狂↔慎），依坐标匹配知音与诤友名士，游历中持续演变。
- **风声压力**：违碍条目直书 +2、微词 +1、留白 0。风声决定山阳之后的途中事件，以及书成之日是否被"请删"。
- **双维度结局**：你编成的书（目录 + 门类厚薄 + 编者按文言小传 + 知音诤友赠言），以及这本书的命运（全本呈上 / 有阙呈上 / 藏之名山）。

## 预览方式

项目不需要 Node.js、包管理器或构建步骤，但数据经 `fetch` 加载，必须通过本地 HTTP 服务预览：在 VS Code 中用 Live Preview 等方式打开 `index.html`（或 `python -m http.server`）。直接以 `file://` 打开时浏览器会拦截本地数据请求，页面会提示数据加载失败。

## 内容维护

- **加一件事**：在 `data/events.json` 的 `events` 里新增条目（含三种立场选择、各自的名士后话与引文），并在对应 `chapters[].events` 里登记 id，页面自动渲染。`censored: true` 的事件会走"直书/微词/留白"三选项并计入风声。
- **加一位名士**：在 `data/sages.json` 新增条目（三条轴取值 -3..3、小传、言行引文即可），他会自动参与知音/诤友匹配。
- **调风声数值**：`data/pressure.json`（上限、阈值）与 `data/events.json` 的 `record.pressureLabels`。
- 旧版答题玩法仍可用：编辑 `data/routes.json`，入口在 `start.html`。
- 存档 key：`shishuo-book-v1`（新玩法）与 `shishuo-grace` / `shishuo-results-*`（旧玩法）。

## 设计说明

无对错判定是这个游戏的根基：选项是三种学术上各有依据的解读立场，名士后话引的每条原文均注明出处（《世说新语》《晋书》或诗文原篇）。机制尽量从书本身长出来——三十六门类是结局骨架，刘义庆招门客著书以避祸的史实是"风声"主线的出处。

## PDF 导出功能（结局页）

在游戏结局页（`ending.html`）点击 **"另存为PDF"** 按钮，可将玩家编成的“世说新书”导出为电子书 PDF 文件。为确保观感和可读性，做了以下改进：

### 1. 字体统一
- 正文与页脚均使用衬线体系列：`Georgia` / `Times New Roman` / `SimSun` / `Microsoft YaHei`
- 正文 12pt，页脚 9pt，建立清晰视觉层次

### 2. UI 元素隐藏
- PDF 输出中自动隐藏所有游戏界面：
  - 导航链接 “回建康城去”
  - 重新开始按钮
  - 导出PDF按钮自身
- 仅保留书本内容，无干扰

### 3. 书式结构重构
- **第一页（标题页）**：
  - 中央大标题 "我的世说新书" (24pt)
  - 创作日期
  - 编者按名言 "笔札落墨，即是人皆可见"
  - 目录（第一章 · 建康受命 至 第五章 · 建康 · 结局）
- **后续页面**：
  - 每页章节大标题，确保分页
  - 四个明确板块：
    - **原文**（古文，首行缩进2em，12pt）
    - **编者按**
    - **名士评**（知音赠言 + 诤友按语）
    - **书的命运**（结局文字）

### 4. 文案优化
- PDF正文中不再出现 "另存为PDF" 等游戏专属按钮文字
- 呼应 "编书人" 主题，提升古典文雅感

## 操作流程

1. 在浏览器中打开 `http://127.0.0.1:8000/ending.html`（必须通过本地 HTTP 服务预览）
2. 进行完整游戏体验至结局
3. 点击结局页的 **"另存为PDF"** 按钮
4. 浏览器弹出打印预览（所见即所得的书式排版）
5. 选择 **"另存为PDF"** 将文件下载到本地
6. 用任意 PDF 阅读器打开阅读

- 生成 PDF 兼容所有主流阅读器（Edge、Chrome、Preview、Adobe Reader 等）
- 已在 Python HTTP 服务器 `python -m http.server 8000` 中验证

## PDF 导出功能结构说明

此功能导出的 PDF 严格遵循以下章节结构，确保内容有序、易读：

### 第一页：标题页
1. **标题**：`世说新书 · XXX编`（XXX为玩家名字）
2. **小标题**：`南朝刘义庆组织编纂`
3. **目录**：第一章 · 建康受命 / 第二章 · 洛阳 / 第三章 · 山阳 / 第四章 · 会稽
4. **分页**：本页作为标题页

### 第二页：编者信息
1. **标题**：`编者信息`
2. **编者姓名**：玩家名字
2. **编纂身份**：南朝刘义庆门客
3. **成书时间**：创作日期
4. **书籍内容**：九件魏晋轶事，记N事，阙M处
5. **编写背景**：受命编撰魏晋轶事集，游历建康—洛阳—山阳—会稽，依三条轴线取舍
6. **编纂历程**：路上经过四地，遇九件事，风声随记录累积
7. **分页**：本页结束，随后进入正文章节

### 后面n章（n为路过的地点数）
1. **标题**：这个地点的名称
2. **二级标题1**：这一故事的名称
   1. **故事的文言文版**：原文
   2. **故事的现代文翻译版**：现代文
   3. **玩家当时做出的选择，代表玩家的立场**：选择文本 + 轴向判定
   4. **玩家冒的后果，也就是风声**：记入哪一门，风声变化
3. **以此类推，取决于在这个地点经历的故事数**
4. **分页**：章节末尾再分页，**不是**每个故事分一页，而是将同一章节的所有故事连续排版，章节之间另起新页
