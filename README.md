# 世说新语·名士风云

一个以《世说新语》和魏晋名士文化为主题的网页小游戏项目，旨在通过轻量、直观的互动页面，让更多同学了解并喜欢中国传统文学作品。

本项目由初中生维护，目前处于界面与基础流程开发阶段。

## 当前功能

- 首页展示游戏标题、魏晋风骨主题文案和水墨背景。
- `start.html` 提供可运行的研学案卷 demo：四条门类线路、原文与译文、重点词提示和情境答题。
- 答题会即时反馈，答对增加风度，答错进入复习模式并显示文本解析。
- 风度可用于向谢道韫请教，获得额外札记；不设战力、排行榜或抽卡。
- 介绍页说明游戏的古文研学目标、玩法和内容边界。
- 主游戏页面支持桌面端与移动端布局。
- 使用本地字体 `ZHSJ-basic.woff2`，保留约 7000 个通用规范汉字，文件大小约 1.3MB，适合网页加载。
- 背景图片加载失败时仍能显示页面基本内容，不会阻塞入口。

## 运行方式

本项目不需要安装依赖或构建项目，可以直接用浏览器打开 `index.html`。

也可以在项目目录启动任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/index.html
```

使用静态服务器时，字体和图片资源在不同浏览器中的加载行为通常更加稳定。

## 字体说明

项目使用中华书局宋体风格的通用汉字子集 `ZHSJ-basic.woff2`。完整字体文件体积较大，因此当前网页只加载约 7000 个通用规范汉字，以降低首屏资源大小。

如果后续游戏内容需要更多生僻字，建议为生僻字制作独立字体子集，并只在对应页面或文字模块中按需加载，避免增加所有页面的首屏负担。

使用字体前请确认字体授权允许转换为 WOFF2 并用于网页分发。

## 维护说明

- 页面文案使用简体中文，文件编码为 UTF-8。
- 修改背景图时，请同步检查 `css/style.css` 或对应 JavaScript 中的资源路径。
- 修改字体文件名后，需要同步更新 `css/style.css`、`intro.html` 以及页面加载脚本中的字体检测名称和路径。
